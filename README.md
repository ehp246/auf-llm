# Auf LLM

## Introduction
A library built on top of [Auf REST](https://mvnrepository.com/artifact/me.ehp246/auf-rest) to interact with LLMs through APIs, e.g., [DeepSeek API](https://api-docs.deepseek.com/).

## Runtime
The latest version requires the following to run:
* <a href='https://openjdk.org/projects/jdk/21/'>Java 21</a>
* <a href='https://mvnrepository.com/artifact/me.ehp246/auf-rest'>Auf REST 6</a>
